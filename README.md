# akash-deploy-rs

Standalone, trait-based Akash deployment workflow engine. No framework coupling.

## Install

Core only (SDL parsing, manifest building, workflow engine):

```toml
[dependencies]
akash-deploy-rs = { version = "0.0.6" }
```

Full client with gRPC, signing, and file storage:

```toml
[dependencies]
akash-deploy-rs = { version = "0.0.6", features = ["default-client", "file-storage"] }
```

## Quick Start

```rust
use akash_deploy_rs::*;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mnemonic = std::env::var("TEST_MNEMONIC")?;
    let client = AkashClient::new_from_mnemonic(
        &mnemonic, "https://rpc.akashnet.net:443", "https://grpc.akashnet.net:443",
    ).await?;
    let signer = KeySigner::new_mnemonic_str(&mnemonic, None)
        .map_err(|e| format!("signer: {e:?}"))?;

    let sdl = std::fs::read_to_string("deploy.yaml")?;
    let mut state = DeploymentState::new("my-app", client.address()).with_sdl(&sdl);
    let workflow = DeploymentWorkflow::new(&client, &signer, Default::default());

    loop {
        match workflow.advance(&mut state).await? {
            StepResult::Continue => continue,
            StepResult::NeedsInput(InputRequired::SelectProvider { bids }) => {
                DeploymentWorkflow::<AkashClient>::select_provider(&mut state, &bids[0].provider)?;
            }
            StepResult::Complete => { break; }
            StepResult::Failed(reason) => return Err(reason.into()),
            _ => {}
        }
    }
    Ok(())
}
```

use akash_deploy_rs::{ManifestBuilder, to_canonical_json};

let builder = ManifestBuilder::new(&owner, dseq);
let groups = builder.build_from_sdl(sdl_yaml)?;

## Custom Backend

Implement `AkashBackend` to bring your own transport and storage:

```rust
struct MyBackend { /* ... */ }
impl AkashBackend for MyBackend {
    type Signer = MySigner;
    // query_balance, broadcast_create_deployment, send_manifest, etc.
}
```

## Manifest Serialization Rules

Provider validation requires byte-identical JSON. `ManifestBuilder` handles all of these:

| Rule | Detail |
|------|--------|
| CPU units | String millicores: `"1000"` not `1.0` |
| Memory/storage sizes | String bytes: `"536870912"` not int |
| Memory/storage field name | `"size"` (Go JSON tag), not `"quantity"` (proto) |
| Empty arrays | `null` not `[]` for command/args/env |
| Field names | camelCase: `externalPort`, `httpOptions`, `readOnly` |
| GPU attributes | Composite keys: `vendor/nvidia/model/h100/ram/80Gi` |
| Storage attributes | Sorted by key |
| Services | Sorted by name |
| Resource endpoints | Only global exposes; GroupSpec `kind = 0` (SHARED_HTTP) |

## JWT Authentication

Akash providers use self-attested ES256K JWTs. No challenge-response -- each request is validated against the on-chain public key. The workflow handles this during `EnsureAuth`.

```rust
let claims = JwtClaims::new("akash1youraddress...");
let jwt = JwtBuilder::new().build_and_sign(&claims, |msg| signer.sign(msg))?;
```

## SDL Templates

Enabled by default. Use `${VAR}` placeholders:

```yaml
services:
  web:
    image: ${IMAGE}:${VERSION}
    expose:
      - port: ${PORT}
        as: ${PORT}
        to:
          - global: true
```

```rust
let template = SdlTemplate::new(template_content)?;
template.validate(&defaults)?;
let processed = template.process(&variables, &defaults)?;
```
